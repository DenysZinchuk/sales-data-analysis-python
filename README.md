## Dataset

The dataset contains three tables:

- `events.csv` — sales transactions
- `products.csv` — product categories
- `countries.csv` — countries and regions

## Key Metrics

The analysis includes:

- Total Orders
- Total Revenue
- Total Costs
- Total Profit
- Profit Margin
- Countries Covered
- Average Shipping Time
